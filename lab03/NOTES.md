# Журнал workshop lab03

## Сравнение и поиск изменений

`git log --oneline --stat` показал краткую историю коммитов и количество изменённых строк в файлах.

`git diff HEAD~2 HEAD -- lab03/calc.py` сравнил содержимое calc.py в двух состояниях и показал изменения между ними.

`git show HEAD~1` показал информацию о конкретном коммите и созданные этим коммитом изменения.

`git log` показывает историю коммитов, `git diff` сравнивает два состояния, а `git show` подробно показывает выбранный объект или коммит.

`git log -S"def"` нашёл коммиты, в которых изменялось количество строк с текстом `def`. В моём проекте это коммиты, добавлявшие функции.

`git blame lab03/calc.py` показал для каждой строки последний изменивший её коммит, автора и дату.

## Восстановление файла

`git restore lab03/calc.py` вернул файл в состояние последнего коммита и удалил незакоммиченные изменения.

`git restore --source=HEAD~2 lab03/calc.py` взял содержимое файла из более старого коммита и поместил его в рабочую папку.

Обе команды перезаписывают незакоммиченные правки, поэтому важные изменения перед восстановлением нужно сохранить.
